# 🎮 Galaxy Striker GB - Perang Bintang

Game *retro space shooter* bergaya konsol genggam klasik **Game Boy** yang dibangun menggunakan HTML5 Canvas dan Web Audio API (Chiptune Synthesizer).

## ✨ Fitur Utama
- **3 Nyawa & Item Drop**: Hati tambahan (`H`), Upgrade Senjata (`W`), dan Bom Super Nova (`B`).
- **4 Level Senjata**: *Single Laser*, *Twin Blaster*, *3-Way Spread Plasma*, dan *Heavy Ion Beam*.
- **Musuh & Raja Bos (Boss Fight)**: Setiap naik level, armada musuh dan pesawat Bos semakin kuat.
- **Mode Layar Ganda**: Mendukung layar Warna Arcade dan Hijau Klasik Game Boy (DMG).
- **Kontrol Lintas Perangkat**: Bisa dimainkan dengan layar sentuh (HP/Tablet) maupun Keyboard (PC/Laptop).

## 🕹️ Cara Bermain
- **Gerak Pesawat**: D-Pad Layar / Tombol Panah / `W, A, S, D`
- **Tembak Laser (Tombol A)**: Tekan `A` di layar / `Spasi` / `Z`
- **Bom Super Nova (Tombol B)**: Tekan `B` di layar / `X` / `Shift`
- **Mulai / Jeda (START)**: Tekan `START` / `Enter`
- **Ganti Warna Layar (SELECT)**: Tekan `SELECT` / `C`
